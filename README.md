# align-with-me

`align-with-me` 是一个面向 Agent 的协作技能：在产品、工作流、自动化或系统变更开始之前，先把“用户想要看到什么”说清楚，再决定“应该怎么实现”。

## 为什么需要这个技能

Agent 很容易快速进入实现模式：看到需求后立即选择架构、修改代码、增加功能。但“做出来”不等于“做对了”。如果没有先确认用户真正想要的结果，常见痛点包括：

- 实现了技术上合理、用户实际上不需要的功能；
- 误解了“当我做 X，我应该看到 Y”的真实场景，直到交付时才发现偏题；
- 工程细节、性能优化和优雅设计挤占了最小可用结果，导致范围悄悄膨胀；
- Agent 自行填补需求中的歧义，关键假设直到返工时才暴露；
- 内部测试全部通过，但用户仍然没有直观、可操作的方式判断结果是否满足预期。

## 它解决什么问题

这个技能把“用户可观察的结果”设为工作的源头和终点：

1. **先对齐意图**：用“你希望：当你做 X 时，会看到 Y，并通过 Z 验证”重述需求，并等待用户确认。
2. **让假设可否决**：确认后列出假设；会改变结果或范围的歧义交给用户决策，不由 Agent 默默猜测。
3. **分清 MVP 和扩展**：计划只把能证明目标的最小端到端工作放进 MVP，其余优化和附加想法明确标为可忽略的扩展。
4. **在用户层验收**：交付时说明用户现在能做什么、会看到什么，以及如何用真实操作验证结果。

它解决的不是“Agent 不会写代码”，而是“Agent 写了很多代码，却没有和用户想要的体验对齐”。

## 一句话安装提示词

将下面这一句直接发给 Agent：

> 请将当前仓库根目录的 `SKILL.md` 和 `agents/openai.yaml` 安装为名为 `align-with-me` 的 Agent 技能，并在之后涉及产品、工作流、自动化或系统变更的任务中启用它。
